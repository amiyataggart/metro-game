# Network coverage, scope & guess matching — design

_2026-10-12 · status: approved; §3 scope approved by user 2026-10-12_

## Goal

Every station on the map can be entered by at least one name; typing a name
never lights a wrong station; each line's stations match the real service
pattern within a deliberately "London" scope.

## Decisions (agreed with user)

| Topic | Decision |
|---|---|
| Boundary | Per-line end stations (§3), replacing `DISPLAY_BOUNDS` clipping + `THAMESLINK_TRIM` |
| Grouping | Same place / name variants light together ("London X" ≡ "X"; one curated King's Cross–St Pancras group). Distinct names (Waterloo East, Monument, Euston Square, Tower Gateway, Woolwich Arsenal) need their own guess |
| Typos | One edit (OSA: adjacent swap, insert, delete, substitute), query ≥4 chars, only when exactly one **group** is within distance 1 — counting all real GB station names as decoys |
| Shorthand | Curated unambiguous aliases only (T5, KX, Olympia, Ashford Surrey…). Ambiguous partials (Heathrow, Walthamstow, Bromley) → "be more specific" |
| Source of truth | Curated per-line service tables; OSM supplies coordinates + track geometry |
| Operators | Add London Northwestern, Eurostar, London Cable Car. Keep EMR, Heathrow/Gatwick Express, Southeastern high speed. Exclude Avanti, LNER, Lumo, Grand Central, Hull Trains, CrossCountry, Caledonian Sleeper |

## 1. Tests (Vitest)

`npm test` runs Vitest. Suites:

1. **Reachability** — for every station feature on the map, its `name` and each
   `alternate_names` entry resolves to a result containing that station.
2. **No false positives** — exact name of station X resolves only to X's group.
3. **Typo exhaustive** — for every station name, generate every OSA-distance-1
   variant; `resolve(variant)` must equal a brute-force oracle (exact match →
   that group; else unique group within 1 among game+decoy names → that group if
   it is a game group; else rejected). Never a group not within distance 1.
4. **Golden queries** — e.g. `victoria`/`london victoria` → Victoria + London
   Victoria; `kx`/`st pancras`/`kings cross` → all four KX/StP stations;
   `cambridge south` → never Cambridge North; `barking` → Barking only;
   `barling`, `maor park` → rejected (ambiguous); `marlyebone`, `wimbeldon`,
   `clapham juntcion` → accepted; `heathrow` → ambiguous; `upwey` (real
   station, not in game) → rejected, not Upney.
5. **Data consistency** — features.json line membership == service tables;
   no station beyond its line's end stations; no duplicate/platform-named
   stations (`Ashford Platform 1`, `Stroud platform 1`).

## 2. Matcher — `src/lib/matching/`

Pure TS, no React, no Fuse (remove `fuse.js` dependency once unused).

- `normalize(s)`: lowercase; strip diacritics; bracket contents kept, brackets
  removed; drop apostrophes; `&`/`and` removed; `saint`/`street`→`st`;
  `road`→`rd`; leading `london ` removed; strip non-alphanumerics.
- `buildIndex(features, aliases, decoys)`: normalised key → group id. Groups =
  union of (same normalised name) ∪ (curated groups in `aliases.ts`). A key
  mapping to >1 group (ambiguous partial) is stored as ambiguous.
- `resolve(query)` → `{ kind: 'match', ids } | { kind: 'ambiguous' } | { kind: 'none' }`.
  Exact key first; else OSA-1 neighbourhood (deletion-neighbourhood index for
  speed) over game keys + decoy keys; accept only a single game group.
- `src/app/(game)/london/data/aliases.ts`: curated groups + aliases (moves the
  existing `alternate_names` intent here; features keep theirs too).
- `src/app/(game)/london/data/gb-station-names.json`: all GB railway station
  names from OSM (decoys), generated by a script, committed.
- `Input.tsx` uses `resolve`; new i18n string for "be more specific".
  Already-found handling unchanged.

Basingstoke, Medway towns, Milton Keynes, Colchester, Tunbridge Wells/Tonbridge.

All of LU, Overground, Elizabeth, DLR, Trams, Heathrow Express, c2c, Cable Car
in full. Others kept from London out to (inclusive):

## 4. Service tables & data

- `src/app/(game)/london/services/<Line>.ts`: ordered calling patterns per
  service (current timetable, all-stations patterns; skip-stop variants only
  matter for station membership). Line = operator key as today.
- `scripts/build-stations.js`: regenerates features.json membership from the
  tables. Coordinates from existing features, else OSM station nodes. Station
  `id`s of existing stations are preserved; new stations get new ids.
- `fetch-osm-routes.js` matchers: accept `Abellio Greater Anglia`, GTR-tagged
  Southern (`SN:` / `Train Southern`), `South Eastern`/`Southeastern Railway(s)`;
  add LNWR (`operator=West Midlands Trains`, name `LNWR:`), Eurostar, Cable Car.
- Services with no OSM relation (Southern WLL, etc.): geometry routed between
  consecutive stops over the OSM rail graph (reuse `build-newtracks.js`),
  then `build-ribbons.js` as usual.
- Config: new `LINES` entries (TfL-map colours) + picker groups.
- Fixes: add missing stations (Albany Park, Belvedere, Chelsfield, Chessington
  N/S, Erith, Falconwood, Knockholt, Lee, Mottingham, Purley Oaks, Sudbury &
  Harrow Road, Woolwich Dockyard + in-scope outer ones); `Ashford Platform 1/2`
  → `Ashford (Surrey)`; Cambridge South (new station, Thameslink + Great Northern + Greater Anglia — confirm current calling pattern).
